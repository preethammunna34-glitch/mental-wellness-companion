# 🌿 Agentic Mental Wellness Companion

A production-ready, multi-agent AI system designed to provide a safe, empathetic conversational space. Built with a focus on deterministic safety, real-time streaming, and persistent memory.

## 🚀 System Architecture

This project moves beyond standard LLM wrappers by implementing a **LangGraph State Machine** to strictly control the AI's conversational boundaries.

* **Frontend (React / Vite):** A "Calm Tech" UI utilizing `framer-motion` for fluid animations and smooth message rendering.
* **Backend (FastAPI):** A robust async Python backend exposing a Server-Sent Events (SSE) endpoint for real-time text streaming.
* **AI Orchestration (LangGraph):** A multi-node state graph that actively routes traffic.
* **Safety Gatekeeper:** Evaluates lexical heuristics and semantic risk scores *before* generation, instantly routing high-risk inputs to a hardcoded Crisis Protocol.
* **Persistent Memory:** Utilizes SQLite and LangGraph Checkpointers to maintain long-term user context across sessions.

## ✨ Key Features
* **Streaming Responses:** Words render on the frontend in real-time as they are generated by the LLM, reducing latency anxiety.
* **Contextual Awareness:** The agent remembers past interactions and user details across page reloads using persistent state vectors.
* **LLM-as-a-Judge Evaluation:** Safety routing logic was rigorously tested and verified for 100% accuracy using custom LangSmith evaluators.

## 🛠️ Tech Stack
* **Frontend:** React, Vite, Framer Motion, Lucide Icons
* **Backend:** FastAPI, Uvicorn, Python 3.12
* **AI / Data:** LangChain, LangGraph, LangSmith, OpenRouter (Gemini / Llama 3)
* **Database:** SQLite (MemorySaver Checkpointing)
